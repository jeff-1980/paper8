# Split manifests

Written by `splits/make_split_manifests.py` (run from the repository root; `DATA_ROOT` must contain
`cwru_12k_de/` for the CWRU part).

* `cwru_split_manifest.csv` — one row per CWRU recording (40): class metadata, file length, the
  train / val / test segment boundaries `[seg_start, seg_end)` along the time axis (70 / 15 / 15 %),
  the two guard gaps (2048 samples each), the number of windows per segment (window 2048, stride
  1024, extracted inside each segment only), the end of the last window of each segment, and the
  index range `[a, b)` of the recording's windows in the pooled train / val / test sets. Generated by
  importing `bearmamba3.data_cwru_leakfree.CWRULeakfreeSplitBuilder` on the raw files and checked to
  be identical to the `split_index.json` written at training time (every CWRU result directory in
  `results/` carries the same `split_index.json` and a `disjointness_check.json` with 40/40 files
  passing). The split does not depend on the seed or the noise level.
* `xjtu_designs.csv` / `xjtu_designs.json` — for each XJTU-SY design (condition 2 → 3, the four
  condition-3 LOBO folds, the three leave-one-condition-out folds, every OR coverage-sweep cell, the
  first coverage sweep `bm3_COV*`, and the IR coverage sweep `ir_coverage_p14_*`), the train and test
  bearings with class, degraded-phase onset file index (H-channel rule) and window count, taken from
  `audit/onset_audit.csv`; windows do not overlap (16 per file). Cross-condition and LOBO designs are
  built in the code (`make_cross_condition_split`, `make_lobo_folds` in `bearmamba3/data_xjtu.py`);
  the other designs list their bearings explicitly in the config (`train_bearings`, `test_bearings`).
